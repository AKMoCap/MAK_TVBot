A trend-following long-only strategy that combines EMA crossovers for trend direction, Anchored VWAP for dynamic support confirmation, and RSI momentum for pullback entry timing. Designed for BTC/USD on daily or 4-hour timeframes.

Entry Conditions (Long)
  1. EMA 20 > EMA 50 — Short-term trend is bullish
  2. EMA 50 > EMA 200 — Long-term uptrend confirmed
  3. Close > Auto AVWAP Low — Price above dynamic VWAP support
  4. RSI(14) < 50 and rising for 2+ bars — Momentum pullback turning up
  5. No open position — One trade at a time (pyramiding disabled)
Exit Conditions
  • Take Profit: +10% gain from entry price
  • Stop Loss: -5% drawdown from entry price
Recommendation: The strategy adds an EMA 50 > EMA 200 filter beyond the user-specified EMA 20 > EMA 50 to reduce whipsaws in sideways markets. The RSI threshold is tightened to 45 (configurable) for earlier momentum detection.
Indicator Components

Exponential Moving Averages smooth price data and reveal trend direction. Faster EMAs react sooner to price changes; slower EMAs confirm the broader trend.

EMA Role Chart Color
EMA 20 Fast signal — captures short-term momentum Blue
EMA 50 Medium trend — crossover trigger with EMA 20 Pink
EMA 100 Slow trend — plotted for reference Orange
EMA 200 Long-term trend filter — EMA 50 must be above this Purple

Entry logic: EMA 20 > EMA 50 confirms short-term bullishness. EMA 50 > EMA 200 confirms the macro uptrend, filtering out counter-trend entries.

The Auto Anchored VWAP calculates a volume-weighted average price anchored from significant pivot lows detected by a Stochastic RSI system. The "Low AVWAP" line acts as dynamic support that adapts as new anchor points form.

How the anchor works:
  1. A Stochastic RSI is computed from RSI(14) with a 14-period lookback
  2. When the Stochastic K line crosses above the D line in the oversold zone (<20), a new anchor point is set
  3. From the anchor bar forward, cumulative (volume × low) and cumulative volume are summed
  4. Low AVWAP = cumulative sum / cumulative volume — this creates a rising support floor during uptrends

Entry logic: Price must be above the Low AVWAP, confirming the current price is supported by volume-weighted demand from the last significant low.

The Relative Strength Index (14) measures momentum on a 0–100 scale. Values below 50 indicate the asset has pulled back from recent highs, creating a potential buy-the-dip opportunity in an uptrend.

Momentum confirmation:
  • RSI < 50: Price has pulled back (not overbought)
  • RSI rising for 2+ bars: Momentum is turning upward from the pullback
  • The threshold (default 45) and confirmation bars (default 2) are adjustable inputs

Why not wait for RSI > 50? By entering while RSI is still below 50 but rising, the strategy catches the early recovery phase, improving the risk/reward ratio.

Pine Script v5 Strategy Code 
//@version=5
strategy("MAK EMA + AVWAP + RSI Strategy",
     overlay              = true,
     initial_capital      = 100000,
     default_qty_type     = strategy.percent_of_equity,
     default_qty_value    = 10,
     commission_type      = strategy.commission.percent,
     commission_value     = 0.0,
     pyramiding           = 0,
     calc_on_every_tick   = false)

// =============================================================================
// INPUT PARAMETERS
// =============================================================================

// EMA Settings
emaFastLen   = input.int(20,  "EMA Fast",   group="EMA Settings")
emaMidLen    = input.int(50,  "EMA Mid",    group="EMA Settings")
emaSlow1Len  = input.int(100, "EMA Slow 1", group="EMA Settings")
emaSlow2Len  = input.int(200, "EMA Slow 2", group="EMA Settings")

// RSI Settings
rsiLength      = input.int(14, "RSI Length",          group="RSI Settings")
rsiThreshold   = input.int(45, "RSI Entry Threshold", group="RSI Settings", minval=20, maxval=60,
                 tooltip="RSI must be below this value for a pullback entry. Default 45.")
rsiConfirmBars = input.int(2,  "RSI Rising Bars",     group="RSI Settings", minval=1, maxval=5,
                 tooltip="Number of consecutive bars RSI must be rising to confirm momentum turn.")

// Auto AVWAP Settings (Stochastic RSI Anchor)
avwapRsiLen  = input.int(14, "AVWAP RSI Length",      group="AVWAP Settings")
avwapStochLen = input.int(14, "AVWAP Stochastic Length", group="AVWAP Settings")
avwapSmoothK = input.int(3,  "Stoch K Smoothing",     group="AVWAP Settings")
avwapSmoothD = input.int(3,  "Stoch D Smoothing",     group="AVWAP Settings")
avwapStochOS = input.int(20, "Stoch Oversold Level",   group="AVWAP Settings", minval=5, maxval=40,
               tooltip="K must cross above D below this level to anchor a new AVWAP.")

// Risk Management
takeProfitPct = input.float(10.0, "Take Profit %", group="Risk Management", minval=1.0, maxval=50.0, step=0.5)
stopLossPct   = input.float(5.0,  "Stop Loss %",   group="Risk Management", minval=1.0, maxval=25.0, step=0.5)

// =============================================================================
// EMA CALCULATIONS
// =============================================================================

ema20  = ta.ema(close, emaFastLen)
ema50  = ta.ema(close, emaMidLen)
ema100 = ta.ema(close, emaSlow1Len)
ema200 = ta.ema(close, emaSlow2Len)

// =============================================================================
// AUTO AVWAP (Anchored VWAP using Stochastic RSI for anchor detection)
// =============================================================================

// Stochastic RSI to find significant low pivot points
avwapRsi   = ta.rsi(close, avwapRsiLen)
avwapStoch = ta.stoch(avwapRsi, avwapRsi, avwapRsi, avwapStochLen)
avwapK     = ta.sma(avwapStoch, avwapSmoothK)
avwapD     = ta.sma(avwapK, avwapSmoothD)

// Anchor signal: Stoch RSI K crosses above D while in oversold zone
anchorSignal = ta.crossover(avwapK, avwapD) and avwapK[1] < avwapStochOS

// Cumulative volume-weighted low from last anchor point
var float cumVolLow = 0.0
var float cumVol    = 0.0

if anchorSignal
    cumVolLow := volume * low
    cumVol    := volume
else
    cumVolLow += volume * low
    cumVol    += volume

loAVWAP = cumVol > 0 ? cumVolLow / cumVol : low

// =============================================================================
// RSI CALCULATION & MOMENTUM CONFIRMATION
// =============================================================================

rsiValue = ta.rsi(close, rsiLength)

// Check that RSI has been rising for N consecutive bars
rsiRising = true
for i = 1 to rsiConfirmBars
    if rsiValue[i - 1] <= rsiValue[i]
        rsiRising := false

// =============================================================================
// ENTRY CONDITIONS (Long Only)
// =============================================================================

emaBullish     = ema20 > ema50 and ema50 > ema200
priceAboveVWAP = close > loAVWAP
rsiCondition   = rsiValue < rsiThreshold and rsiRising
notInPosition  = strategy.position_size == 0

longEntry = emaBullish and priceAboveVWAP and rsiCondition and notInPosition

// =============================================================================
// STRATEGY EXECUTION
// =============================================================================

if longEntry
    strategy.entry("Long", strategy.long)
    alert('{"action":"buy","coin":"BTC","indicator":"ema-avwap-rsi"}', alert.freq_once_per_bar)

// Take Profit & Stop Loss
if strategy.position_size > 0
    strategy.exit("TP/SL", "Long",
         profit = close * (takeProfitPct / 100) / syminfo.mintick,
         loss   = close * (stopLossPct / 100) / syminfo.mintick)

// =============================================================================
// PLOTS
// =============================================================================

plot(ema20,   "EMA 20",    color=color.new(#2962FF, 0), linewidth=1)
plot(ema50,   "EMA 50",    color=color.new(#E91E63, 0), linewidth=1)
plot(ema100,  "EMA 100",   color=color.new(#FF9800, 0), linewidth=1)
plot(ema200,  "EMA 200",   color=color.new(#9C27B0, 0), linewidth=2)
plot(loAVWAP, "AVWAP Low", color=color.new(#00BCD4, 0), linewidth=2, style=plot.style_stepline)

// Highlight background when in a long position
bgcolor(strategy.position_size > 0 ? color.new(color.green, 92) : na, title="In Position")

// Entry signal markers
plotshape(longEntry, "Buy Signal", shape.triangleup, location.belowbar,
          color=color.green, size=size.small, text="BUY")
